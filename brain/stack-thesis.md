# The stack thesis

One thesis at layers, one owner per layer: isolation (K2 bwrap + spawn permit), accountability (hash-chained receipts, SQLite ledger), calibration (`route` + `decide`), verification (the tiered gate, §3 of the stack map), memory (`brain/`), craft (pstack playbooks).

HEE v4 owns the unit of work, the verdict, the receipt, the socket, the router, isolation and recovery. Every other repo contributes a format or a pattern, not a runtime: noodle (orders-file shape, mode dial), pstack (brief, playbooks, `correct` ladder), verification-skill (feature map), deep-diff-forge (sealed observation), LoomLattice (chain discipline; display projection only).
