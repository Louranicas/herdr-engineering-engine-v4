Each line: `cast when → the move (≤ 15 words) → spell`. The v4 id that mechanises it follows where one exists.

- designing any gate, score or fitness check → the measurer lives outside the measured, welded shut → `spell:The Welded Judge` `AP-33`
- a loop whose only exit is success → the honest "gated / did not converge" is the skill → `spell:Refusal is Competence` `P8`
- declaring an integration or wire "done" → send real signal and watch the far end light up → `spell:Send Signal Through the Wire` `D-16`
- a story that fits every observation → probe for the mechanism; one probe collapses folklore → `spell:Mechanism, Not Symptom` `MM#16`
- trusting a name, worktree or recalled fact → diff before you believe; a name is not a hash → `spell:Identity is Not Proximity` `AP-32`
- stopping a process → find the holder; kill by explicit PID, never `pkill -f` → `spell:Kill by PID, Not by Pattern` `AP-38`
- deciding what to automate → automate dense-signal loops; gate sparse ambitious ones behind a human → `spell:Automate the Humble, Freeze the Ambitious` `D-04`
- about to scaffold → design the plan first; artifacts derive from it, sync-gated → `spell:Draught Before You Weave` `D-03`
- a plan written once → re-attack from skipped frames, esp. dogfood; fold survivors in → `spell:Harden by the Frame You Didn't Take` `D-02`
- designing a failure path → make failures as legible as successes; refusals write themselves down → `spell:Witness the Collapse` `AP-29`
- proof you generated for your own loop → keep a skeptic outside the work, defaulting to disbelief → `spell:Distrust the Evidence You Minted` `AP-34`
- reporting a set of passing gates → know which gate bore the weight; sort load-bearing from customary → `spell:Weigh Ceremony Against Necessity` `L1`
